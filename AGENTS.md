- KIDO PAY is an in-memory interactive hackathon demo with shared React state between parent and teen views; no real accounts or financial transfers are implied.
- Keep monetary balances in integer cents and permission decisions in browser-safe wallet helpers so simulated spending and approvals can be tested precisely.
- Use the home route for the dual-role experience and semantic theme tokens for all visual states; mobile removes the desktop phone frame.
